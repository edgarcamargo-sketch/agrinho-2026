# 🌿 EcoSolo - Painel de Compostagem Doméstica e Agrícola

A aplicação **EcoSolo** é uma ferramenta interativa desenvolvida exclusivamente para o **Concurso Agrinho 2026**. O projeto foi construído sob o tema oficial *"Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente"*, permitindo que pequenos produtores agrícolas e cidadãos urbanos calculem com precisão a proporção ideal de resíduos orgânicos para criar um adubo natural de altíssima qualidade.

---

## 🎯 Objetivo e Justificativa Temática
O descarte incorreto de resíduos orgânicos sobrecarrega os aterros sanitários e gera gases poluentes, enquanto o uso excessivo de fertilizantes sintéticos degrada o solo a longo prazo. 

O **EcoSolo** atua diretamente nesse gargalo, promovendo a economia circular. A ferramenta conscientiza o usuário sobre o equilíbrio entre materiais ricos em Nitrogênio (Verdes) e Carbono (Castanhos). O resultado prático é a produção de um biofertilizante rico, que aumenta a produtividade no campo sem agredir os ecossistemas, materializando o conceito de sustentabilidade do Concurso Agrinho.

---

## 💻 Funcionalidades do Projeto
* **Calculadora Automatizada de Proporção:** Analisa o peso inserido de resíduos e calcula se a mistura atingiu a proporção ideal de decomposição (2 a 3 partes de Carbono para 1 de Nitrogênio).
* **Feedback Inteligente e Sustentável:** Exibe alertas visuais dinâmicos e dicas práticas sobre como corrigir o composto caso ele apresente excessos.
* **Interface Adaptável (Saudação Dinâmica):** O sistema identifica o horário do dispositivo do usuário para exibir uma mensagem personalizada de boas-vindas focada no produtor sustentável.

---

## 🚀 Tecnologias Utilizadas
Para cumprir rigorosamente as regras do edital, o projeto foi desenvolvido de forma 100% nativa, sem o uso de frameworks, bibliotecas externas ou códigos inline:

* **HTML5:** Estruturação semântica avançada para garantir acessibilidade e legibilidade.
* **CSS3:** Estilização baseada em variáveis de ambiente, Flexbox e Media Queries para garantir total responsividade em telas de desktop.
* **JavaScript (ES6):** Lógica de programação estruturada, validação estrita de formulários e manipulação dinâmica do DOM.
